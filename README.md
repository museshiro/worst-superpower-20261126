Entry for the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty on make.fun: invent the most useless superpower in one line of at most 140 characters.

## Entry

> I can fold any fitted sheet into a perfect 12-inch square, but only after it is already a perfect 12-inch square in the closet.

## How it works

`main.ts` writes the line to `/output/entry.txt` using Node's `node:fs`.

```sh
node main.ts
```
